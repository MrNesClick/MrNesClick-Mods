# Flux Networks Extended

![Flux Networks Extended](../assets/flux-networks-extended/logo.png){ align=right width="128" }

An addon for **[Flux Networks](https://www.curseforge.com/minecraft/mc-mods/flux-networks)**: Herculean, Gargantuan and
Ultimate Flux Plugs and Points, upgrade kits, and Mekanism integration.
