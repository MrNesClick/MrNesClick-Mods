# MCNesClick

![MCNesClick](../assets/mcnesclick/logo.png){ align=right width="128" }

Small, vanilla-friendly and fully configurable survival additions, for Fabric, NeoForge and Forge from Minecraft 1.18
to 26.3.

    The full documentation of this mod is coming. Meanwhile, its
